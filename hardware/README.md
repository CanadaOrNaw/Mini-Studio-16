# Inherited Microgroove hardware artwork

- `microgroove_labels_v6_preview.png` — the v6 keymap / keycap label reference
  (one key = one function; orange = hold, green = sampling). This doubles as the
  quickest explanation of the whole layout.
- This fork does not currently contain the upstream shell STLs or print-ready
  label SVG. Obtain those from the upstream Microgroove distribution/listings.
- The v6 overlay predates Mini Studio 16's LOOP, EVENT, MOTION, SD TEST, streamed
  sampler, master, and stem page controls. Use `docs/USER_MANUAL.md` during the
  alpha; do not treat the preview as a complete Mini Studio 16 key legend.

Print settings, assembly photos, and the original label application guide live
with the upstream project. A new overlay should be designed only after the
physical UI pass confirms the bindings and readable abbreviations.
